DOM Structure

The Document Object Model (DOM) represents every page of the Maison Vélour website as a structured tree of nodes — the backbone of our web presence.

What is the DOM?

The Document Object Model

The DOM is a programming interface for web documents. It represents the page as a hierarchical tree of objects, allowing scripts to dynamically update the content, structure, and style of a document.

JavaScript Features

Applied JS Features

All pages share a single external JavaScript file (main.js) providing the following features.

Scroll Reveal

IntersectionObserver animates elements into view as users scroll down — applied to all .reveal elements.

Counter Animation

Animated number counters on the homepage stats bar, easing from 0 to target value when visible.

Toast Notifications

Dynamic pop-up notifications for user actions: wishlisting, enquiries, RSVP, and form submissions.

Filter System

JavaScript-driven filtering on the Collections and Events pages — toggle by category/type with smooth visibility transitions.

Tab System

Reusable tabbed panels on the Collections page for SS/AW seasons and on this DOM page for page views.

Form Validation + FAQ

Client-side form validation with field highlighting on the Inquiries page, plus dynamically generated FAQ accordion.
